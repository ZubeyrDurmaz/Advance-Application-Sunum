Section Spacing Utilities

Responsive spacing utilities that scale with viewport size

Section (.section)

This section has responsive bottom margin using var(--space-2xl) on mobile and var(--space-3xl) on tablet+

Small Section (.section-sm)

This section has smaller responsive bottom margin using var(--space-lg) on mobile and var(--space-xl) on tablet+

Large Section (.section-lg)

This section has larger responsive bottom margin using var(--space-3xl) on mobile and clamp(4rem, 6vw, 5rem) on tablet+

Page Main Padding

The .page-main container (this entire page) uses fluid spacing variables for responsive padding

  • Mobile: padding: var(--space-lg) var(--space-md)
  • Tablet (≥768px): padding: var(--space-2xl) var(--space-xl)
  • Desktop (≥1024px): padding: var(--space-3xl) var(--space-2xl)
